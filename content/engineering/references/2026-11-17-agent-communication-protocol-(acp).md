[Welcome](https://agentcommunicationprotocol.dev/introduction/welcome)

The Agent Communication Protocol (ACP) is an open, REST-based protocol that lets AI agents built with different frameworks, by different teams, and on different infrastructure communicate through a standardized API. It supports multimodal messages, synchronous and asynchronous communication, streaming, and offline discovery. This reduces the need for custom integrations between agents, and ACP has since become part of A2A under the Linux Foundation.
