[mex-memory/mex: Team memory for engineers and their AI agents. Lives in your repo. Shared through Git.](https://github.com/mex-memory/mex)

MEX is an open-source tool that stores shared project memory for engineers and their coding agents as Markdown files in a repository's `.mex/` directory. It is shared through Git and linked to code through a local Code Graph. It provides a local Hub for people, plus a CLI and skills for agents such as Claude Code and Codex. Its main workflows are Wiki knowledge, Inbox proposals, and Relay handoffs. It matters because it keeps context, decisions, and handoffs durable and reviewable across teammates and agent sessions, without a hosted service.
