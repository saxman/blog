[The #1 agentic engineering toolkit](https://ecc.tools/)

ECC (Everything Claude Code) is an MIT-licensed, open-source operating layer for AI coding agent harnesses. It provides skills, agents, hooks, planning tools, unified memory and security tooling that give coding agents a shared way of working across Claude Code, Codex, Cursor, OpenCode and Kimi Code. Key components include Plan Canvas for annotating agent plans in the browser, Control Pane for viewing sessions and worktrees, Unified Memory for handing off context between harnesses via CLI and MCP, compute workflows through Itô, and AgentShield, a scanner that checks agent configurations, permissions, hooks and MCP connections for risks such as prompt injection and exposed secrets. A companion GitHub App turns repository history into reviewable guidance, with a free tier, a Pro plan at $19 per active seat per month, and Enterprise options. The project reports over 305k GitHub stars and 1.8m skill installs on skills.sh, and it is sponsored by companies including CodeRabbit, Greptile and Moonshot AI.
