[aipoch/open-science](https://github.com/aipoch/open-science)

The open-source AI research workbench for scientific research and agent workflows. Local-first, model-agnostic desktop app with extensible skills, MCP tools and connectors, Python/R execution and traceable artifacts for reproducible research on macOS, Windows and Linux.
AIPOCH Open-Science is an open-source (Apache-2.0), local-first, model-agnostic AI research workbench for reproducible science. It runs as a desktop app on macOS, Windows, and Linux, and also as a standalone CLI/Web UI and Node.js SDK. Researchers create projects, describe goals in plain language, and let AI agents read files, search the web, run Python/R code in notebooks, query scientific data connectors (48 built-in, plus custom MCP), and produce reports, tables, and figures. Every artifact is stored as an immutable, checksummed version with traceable provenance.
