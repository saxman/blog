This 2018 paper replicates an influential decade-old study on how scientists develop and use software, using an online survey of more than 1,574 R developers enriched with GitHub data. It confirms that scientist-developers mostly work alone, set their own priorities, and learn mainly through self-study. It also finds that some pain points are non-technical, such as interruptions, a lack of collaborators, and the absence of reward systems, which can help educators and researchers support scientific software development.
