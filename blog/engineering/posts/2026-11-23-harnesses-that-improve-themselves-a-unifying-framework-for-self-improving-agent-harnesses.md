[Harnesses That Improve Themselves: A Unifying Framework for Self-Improving Agent Harnesses](https://academy.dair.ai/papers/harnesses-that-improve-themselves-a-unifying-framework-for-self-improving-agent-2611.22299)

A research paper from Google authors proposing a design framework for self-improving agent harnesses, the runtime software around a foundation model that can rewrite its own code. The framework has four editable components and a loop that diagnoses failures, proposes patches, validates them and deploys them. On SWE-bench Lite, gated modular updates came close to full rewrites in accuracy at about a tenth of the token cost and transferred better to a stronger model, though the evaluation used only 40 held-out tasks.
