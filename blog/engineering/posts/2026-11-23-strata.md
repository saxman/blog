[Niko1221/Strata: Qwen3.8-Flash-Next on any consumer hardware: one-click install for Windows / Linux. Strata inference engine, OpenAI/Anthropic API on localhost, optional image input.](https://github.com/niko1221/strata)

Strata is a free, open-source, MIT-licensed app for running large language models locally on your own computer, through a desktop app or a terminal app. It supports NVIDIA, AMD, Intel Arc and Apple Silicon hardware, and provides quantized model packs sized for different RAM and GPU memory budgets. It also offers OpenAI- and Anthropic-compatible APIs, so coding tools such as Claude Code, Codex CLI and OpenCode can use local models with no account and no cloud dependency.
